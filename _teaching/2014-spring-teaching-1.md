实现本地化 RAG 智能问答系统，完成多格式文档解析、文本切分、Embedding 向量化及 FAISS/BM25 混合检索；结合 Cross-Encoder 重排序、递归检索、联网搜索和多来源矛盾检测提升问答质量。基于 Gradio 和 FastAPI 提供 Web UI 与 REST API，并通过用户认证实现知识库隔离。
